For later — how this gets wired up

Connecting real accounts

Instagram

Instagram Basic Display / Graph API

Requires a Meta developer app and a long-lived access token tied to the business account. Once set up, the feed can call the API on a schedule and cache the results — no manual updates needed.

Flickr

Flickr public API

Simpler to set up: a free API key plus your public user ID is enough to pull recent uploads or a specific album, no app review process required.
